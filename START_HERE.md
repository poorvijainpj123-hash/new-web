## 🚀 HOW TO USE

### 1. Open Website
Double-click `index.html` or drag & drop onto browser window

### 2. Explore Regions
- Click "Begin the Journey" button
- OR click any region card on home page

### 3. View Region Details
- Read about region geography, climate, culture, etc.
- Switch between 6 information tabs
- Click on any state to view details

### 4. Explore State
- Read 11 detailed sections about the state
- Click navigation buttons to jump between sections
- View famous places as cards
- Use breadcrumbs to navigate back

### 5. Return & Explore More
- Use "Back" buttons or breadcrumbs
- Click "Explore Another Region" to jump to different regions
- Use header navigation menu anytime
