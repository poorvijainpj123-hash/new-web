## 🌟 SAMPLE CONTENT

### **Rajasthan State Details**
- Capital: Jaipur (Pink City, founded 1727)
- State Animal: Indian Camel
- State Flower: Rohida
- Cultural Hook: "Land of Kings, Deserts & Eternal Ramparts"
- Famous Places: Hawa Mahal, City Palace, Jodhpur Fort, Lake Palace, Meherangarh Fort, Jaisamand Lake
- Traditions: Ghoomar dance, puppet theatre, Holi celebrations
- Art Forms: Miniature paintings, block printing, Bandhani textiles, Kathak dance
- Food: Dal bati churma, Gatte ki subzi, Ker sangri, Bajra roti, Ras malai
- Festivals: Teej, Diwali, Holi, Pushkar Camel Fair

### **Punjab State Details**
- Capital: Chandigarh (planned city)
- State Animal: Lion
- State Flower: Gladiolus
- Cultural Hook: "Granary of India, Land of Five Rivers"
- Famous Places: Golden Temple, Wagah Border, Jallianwala Bagh, Harike Wetland
- Traditions: Bhangra dance, Kirtan music, Langar (communal meal), Gurdwaras
- Art Forms: Bhangra, Giddha, folk music, truck art, phulkari embroidery
- Food: Makki roti, Punjabi chole bhature, Paneer tikka, Lassi
- Festivals: Baisakhi, Lohri, Diwali, Guru Nanak Jayanti

## 📈 EXTENSIBILITY

The website is built to be easily extended:

### **Add More States**
Simply add to the `states` array in `ATLAS_DATA.regions[].states`

### **Add More Regions**
Add new object to `ATLAS_DATA.regions` array with same structure

### **Add More Content**
Expand any section's `content` object with additional paragraphs

### **Customize Colors**
Modify `--region-color` variable or regional color values in CSS

### **Change Typography**
Update `--font-*` variables in `:root` CSS rules
