🎨 DESIGN SYSTEM
═══════════════════════════════════════════════════════════════════════════════

THEME: "Living Manuscript"
  └─ Inspired by ancient Indian palm-leaf manuscripts & Mughal miniatures

COLOR PALETTE:
  Primary:    #0D0905 (Deep saffron-black) — main background
  Accents:    #E8871A (Orange), #8B1A1A (Crimson), #1A6B5E (Teal)
  Highlight:  #C9A84C (Gold) — decorative elements
  Text:       #F2EAD3 (Cream) — readable on dark backgrounds

TYPOGRAPHY:
  Headings:   Cormorant Garamond (serif, editorial)

  Hindi:      Noto Serif Devanagari (authentic script)

  ✨ Mandala SVG patterns
  ✨ Glassmorphism header (blur effect)
  ✨ Smooth animations & transitions

🚀 HOW TO USE
═══════════════════════════════════════════════════════════════════════════════

STEP 1: OPEN
  └─ Double-click index.html or drag onto browser window

STEP 2: EXPLORE
  ├─ Click "Begin the Journey" to view regions
  ├─ Click any region card to view region details
  ├─ Click any state card to view state details
  └─ Use breadcrumbs to navigate back

STEP 3: NAVIGATE
  ├─ Switch tabs on region page (Geography, Climate, Culture, etc.)
  ├─ Click section buttons on state page (History, Food, Festivals, etc.)
  ├─ Use mobile menu on small screens
  └─ All navigation works smoothly
